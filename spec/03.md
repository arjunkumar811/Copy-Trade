PHASE 1 — PRODUCTION PROJECT FOUNDATION

Implement only the foundational backend infrastructure.

Requirements:

1. Environment/configuration management
2. Centralized configuration
3. Database connection management
4. Database migration setup
5. Structured logging
6. Global error handling
7. Request ID / correlation ID
8. Health endpoint
9. Readiness endpoint
10. Graceful shutdown
11. Basic security middleware
12. Basic API structure
13. Test infrastructure

Create a clean structure such as:

src/
  config/
  api/
  db/
  domain/
  services/
  infrastructure/
  middleware/
  utils/

Adapt this to the existing project's technology rather than blindly following it.

Requirements:

- typed configuration
- fail fast if required environment variables are missing
- never log secrets
- connection pooling
- graceful DB shutdown
- consistent API error responses
- request correlation IDs

Add tests for:

- configuration validation
- health endpoint
- invalid configuration
- error handling
- request ID
- database connectivity where practical

Run:

- tests
- type checking
- linting

Fix all failures.

Do not implement wallet authentication, blockchain listeners, queues, or trade execution yet.
