PHASE 3 — SOLANA WALLET AUTHENTICATION

Implement secure wallet-based authentication.

Requirements:

1. User connects a Solana wallet.
2. Backend generates a nonce/challenge.
3. User signs the challenge.
4. Backend verifies the signature.
5. Backend creates/authenticates the user.
6. Prevent replay of old signatures.
7. Nonces expire.
8. Never ask for or store a private key/seed phrase.
9. Never trust wallet address supplied by the client without signature verification.

Create appropriate API endpoints.

Add authentication middleware.

Tests must cover:

- valid signature
- invalid signature
- expired nonce
- reused nonce
- wrong wallet
- malformed request
- unauthorized request

Do not implement trading yet.
