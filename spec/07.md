PHASE 5 — SOLANA BLOCKCHAIN INGESTION

Implement the blockchain ingestion layer.

Requirements:

- isolate Solana RPC/WebSocket logic behind an interface
- support configurable RPC provider
- subscribe/monitor followed trader wallets
- detect relevant transaction activity
- persist source transaction signatures
- handle duplicate events
- reconnect automatically after connection failure
- handle RPC rate limits
- handle temporary network failures
- graceful shutdown
- bounded concurrency

IMPORTANT:

Do NOT execute copy trades yet.

The listener's only responsibility is:

BLOCKCHAIN
    ↓
EVENT
    ↓
VALIDATE
    ↓
PERSIST
    ↓
QUEUE

Do not put business logic for trade execution inside the listener.

Add tests using mocked blockchain responses.

Test:

- new transaction
- duplicate transaction
- malformed transaction
- RPC failure
- reconnect
- rate limit
- listener shutdown
