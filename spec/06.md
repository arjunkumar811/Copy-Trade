PHASE 4 — FOLLOWED TRADERS

Implement the ability for an authenticated user to:

- add a Solana trader wallet to follow
- remove a trader
- list followed traders
- configure copy-trading settings

Settings should eventually support:

- fixed amount per trade
- percentage of user's balance
- maximum trade amount
- maximum daily loss
- maximum slippage
- allowed tokens
- blocked tokens
- enable/disable copying

Validate all settings server-side.

Do not execute trades.

Add unit and integration tests.

Pay special attention to authorization:
a user must only be able to modify their own followed traders/settings.
