PHASE 6 — ASYNCHRONOUS QUEUE SYSTEM

Implement the queue infrastructure.

Required job types:

SOURCE_TRANSACTION_PROCESSING
TRADE_DETECTION
COPY_TRADE_CREATION

Requirements:

- durable jobs
- retries
- exponential backoff
- dead-letter handling
- job IDs
- idempotency
- concurrency limits
- graceful worker shutdown

Architecture:

Blockchain Listener
       ↓
Queue
       ↓
Worker
       ↓
Transaction Processor
       ↓
Database

Multiple workers must be able to run simultaneously without processing the same event twice.

Add tests for:

- successful job
- failed job
- retry
- duplicate job
- dead-letter behavior
- worker restart
- concurrency
- graceful shutdown
